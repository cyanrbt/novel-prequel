# 只读状态检查

## 目的

判断项目是否可以进入下一项创作任务。此工作流不调用模型、不生成正文、不修改任何正式文件。

## 步骤

1. 阅读根目录 `WORKFLOW.md` 和 `init.md`。
2. 读取 `novel/state/current.json`，确认机器状态、上一章和下一章编号。
3. 确认 `novel/chapters/` 中的正式章节从第1章连续到 `last_chapter`。
4. 确认当前事件大纲、正典登记、伏笔登记、里程碑登记和用户偏好合同存在。
5. 核对最新正式章节哈希、盲读结论和用户偏好合同哈希是否仍与 `formal_review_bindings` 一致。
6. 检查是否存在未完成运行；只允许复用输入指纹仍一致的工件。

## 输出

返回以下三项：

- `READY`、`BLOCKED` 或 `WAITING_USER`；
- 支持结论的文件路径和事实；
- 不修改正式内容即可执行的下一步。

若正式审核绑定过期，必须返回 `BLOCKED`，不得开始下一章。
