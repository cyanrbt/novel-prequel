# 创作规则全书（权威规则源）

本文件是创作约束的唯一权威来源。事实依据以 `novel/knowledge/canon_registry.json` 为准，运行状态以 `novel/state/current.json` 为准，风格参数以 `novel/style/compact_style.yaml` 为准，示例锚点以 `novel/style/style_anchors.txt` 为准。

## 1. 原著一致性（P1）

- A 级是原著明确事实：不得修改，只能在注册表允许范围内使用。
- B 级是强暗示或可靠推演：只能写成人物推测、传闻或未证实方向。
- C 级是前传原创：必须服务当前人物与事件，不冒充原著答案。
- 正文不得直接消费原著摘录；Planner 提取依据，Writer 只使用核准后的创作包。
- 原著刻意留白不强行封口。遇到多个解释时保留不确定性。
- 当前年代的禁入人物和现代概念见 registry；任何串线均阻断发布。
- 不复制或近似改写原著的标志性句子、段落、对白、开场结构和人物造型。

## 2. 灵异底层约束（P1）

- 鬼无法被普通方式彻底杀死，只能限制、关押、转移或暂时规避。
- 能对付鬼的只有鬼；普通物理手段至多改变环境、延迟触发或帮助逃生。
- 使用灵异力量必有具体且不可逆的代价。
- 异常行为存在相对稳定的规律，但人物对规律的认识永远可能不完整。
- 新规则必须经历“观察—假说—试错—后果—临时结论”；未充分验证时只能留在 `hypotheses`。
- 人物不得无理由豁免规则；关键解法不得依赖未规划的新设定。

## 3. 连续性与能力闸门（P1）

- 章号连续，时间、地点、在场人物、身体、物品、已知信息与上一章状态相接。
- `unlock_chapter` 之前，能力不能以技能、直觉、威势或变相效果出现。
- 每章至少改变选择、关系、资源、规则假说、身体状态或危险位置中的一项。
- 场景离开后必须留下后果；只有气氛、走路和复述的场景应删除。
- 伏笔播种与回收必须登记。回收不能靠当天新补的解释完成。

## 4. 视角与信息（P1）

- 第三人称限知，只跟随张洞。叙述只能写他当下感知、记忆或根据已有证据作出的推断。
- 禁止“他不知道的是”“与此同时”“在另一边”等越视角切换。
- 叙述者不替人物宣布规则真相，不提前展示远处正在发生的事。
- 事实、人物猜测和读者可疑点必须能区分；推理允许错误且要承担后果。

## 5. 人物（P1/P2）

- 张洞的冷静和决断必须有成长过程。早期不得直接写成后期全知、绝对功利或自带威压的人物。
- 帮助他人必须源于亲缘、旧债、共同风险、现实交换或被迫选择；不靠作者道德评语。
- 人物各有想得到的东西、不肯说的信息和压力下的选择。配角不能只负责讲设定或送死。
- 重大死亡必须改变活人的关系、资源、处境或下一步决定。
- 情绪优先通过具体事务和选择显现，但不得反复套用同一身体动作模板。

## 6. 叙事声音（P2）

- 语气冷静、事实具体、解释克制。恐怖来自正常秩序中可核对的偏差，而非形容词堆积。
- 日常细节要有用途：建立价格、亲缘、债务、距离、作息或安全边界，随后让异常改变它。
- 比喻少而准确，来自人物所处时代和生活经验；不用华丽抒情替代事实。
- 对话推进目标、暴露隐瞒或改变关系。不同人物不能都用同样短句和故作停顿。
- 结尾钩子由本章因果产生，可以安静但必须改变读者对安全、规则或代价的判断。

## 7. 反模板与重复（P1/P2）

- 最近五章不得重复完整长段、累计三次相同长句或明显复制场景顺序。
- 控制破折号和“不是……而是……”；不用整齐列举、四句同构、段末总结制造假深刻。
- 避免固定动作：停步不回头、折纸入怀、守灯到天亮、渡口扔石、眼神变暗等不得成为人物默认反应。
- 避免“这意味着、显然、值得注意的是、命运的齿轮”等作者总结。
- 不按固定感官流水线写每场恐怖；选择最能证明异常的具体证据。

## 8. 单章发布条件

- 规划 JSON 合法，依据 ID 已注册，且存在真实状态变化。
- 正文硬检查无 P1：时代、章号、POV、能力、禁入元素、近期复用均通过。
- 语义审查给出正文中的真实证据，结论为 PASS，且不得推翻静态门禁。
- 正文目标 3500—5000 汉字；1800—8000 为安全范围，质量优先于凑字数。
- 任何失败只保留在工作区，不更新正式章节或状态。连续失败达到上限后停止并交由用户判断。
