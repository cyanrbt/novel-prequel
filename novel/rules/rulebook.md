# 创作规则全书（权威规则源）

本文件负责正文行为与发布门禁；全书卷结构、里程碑和可伸缩长度以 `novel/plots/series_architecture.md` 为最高设计约束。事实依据以 `novel/knowledge/canon_registry.json` 为准，运行状态以 `novel/state/current.json` 为准，里程碑以 `novel/knowledge/arc_registry.json` 为准，伏笔 ID 与回收边界以 `novel/knowledge/foreshadow_registry.json` 为准；风格参数以 `novel/style/compact_style.yaml` 为准。`novel/style/style_anchors.txt` 在完成人工逐段核准前不得进入创作上下文；`novel/foreshadow_tracker.md` 是归档草案，不得作为创作指令。

## 1. 原著一致性（P1）

- A 级是原著明确事实：不得修改，只能在注册表允许范围内使用。
- B 级是强暗示或可靠推演：只能写成人物推测、传闻或未证实方向。
- C 级是前传原创：必须服务当前人物与事件，不冒充原著答案。
- 正文不得直接消费原著摘录；Planner 提取依据，Writer 只使用核准后的创作包。
- 原著刻意留白不强行封口。遇到多个解释时保留不确定性。
- 当前年代的禁入人物和现代概念见 registry；任何串线均阻断发布。
- 不复制或近似改写原著的标志性句子、段落、对白、开场结构和人物造型。

## 2. 灵异底层约束（P1）

- 鬼无法被普通方式彻底杀死，只能限制、关押、转移或暂时规避。
- 能对付鬼的只有鬼；普通物理手段至多改变环境、延迟触发或帮助逃生。
- 使用灵异力量必有具体且不可逆的代价。
- 异常行为存在相对稳定的规律，但人物对规律的认识永远可能不完整。
- 新规则必须在一条事件线内经历“观察—假说—试错—后果—临时结论”；这些环节可以跨数章分布。未充分验证时只能留在 `hypotheses`。
- 人物不得无理由豁免规则；关键解法不得依赖未规划的新设定。

## 3. 连续性与能力闸门（P1）

- 章号连续，时间、地点、在场人物、身体、物品、已知信息与上一章状态相接。
- 能力的 `unlock_after` 里程碑未完成前，能力不能以技能、直觉、威势或变相效果出现；旧的 `unlock_chapter` 仅用于读取旧状态时的兼容，不得新增。
- 每章至少发生一次不可逆的戏剧转折，改变选择、关系、资源、规则假说、身体状态或危险位置中的一项。
- 场景应承担准备、冲突、升级、关系显影或余波中的明确功能；并非每场都要产生不可逆状态变化。只有气氛、走路和复述、且没有改变人物压力的场景应删除。
- 伏笔播种与回收必须登记。回收不能靠当天新补的解释完成。

## 4. 视角与信息（P1）

- 第三人称限知，只跟随张洞。叙述只能写他当下感知、记忆或根据已有证据作出的推断。
- 禁止“他不知道的是”“与此同时”“在另一边”等越视角切换。
- 叙述者不替人物宣布规则真相，不提前展示远处正在发生的事。
- 事实、人物猜测和读者可疑点必须能区分；推理允许错误且要承担后果。

## 5. 人物（P1/P2）

- 张洞的冷静和决断必须有成长过程。早期不得直接写成后期全知、绝对功利或自带威压的人物。
- 帮助他人必须源于亲缘、旧债、共同风险、现实交换或被迫选择；不靠作者道德评语。
- 人物各有想得到的东西、不肯说的信息和压力下的选择。配角不能只负责讲设定或送死。
- 重大死亡必须改变活人的关系、资源、处境或下一步决定。
- 情绪优先通过具体事务和选择显现，但不得反复套用同一身体动作模板。

## 6. 叙事声音（P2）

- 语气冷静、事实具体、解释克制。恐怖来自正常秩序中可核对的偏差，而非形容词堆积。
- 日常细节要有用途：建立价格、亲缘、债务、距离、作息或安全边界，随后让异常改变它。
- 面向当代普通读者写旧时代物件、地名俗称或行业称谓时，首次出现且会影响人物选择、空间判断或异常规则的对象，必须在同一处用可见动作交代其位置、用途与实际后果；不得假定读者认识旧式门锁、船只舱位、票据或计时方式。解释应嵌入人物观察、动作或冲突，不用括号拼音、词条腔说明。
- 除非人物口语、史料或情节必须保留，避免单字生僻称谓。优先使用当代读者可直接理解的词；例如以“木栓/门栓”替代孤立的“闩”。替换后若物件仍陌生，仍须完成首次可视化说明。
- 比喻少而准确，来自人物所处时代和生活经验；不用华丽抒情替代事实。
- 对话推进目标、暴露隐瞒或改变关系。不同人物不能都用同样短句和故作停顿；在不引入现代组织、技术或严重史实错位的前提下，允许有服务当下读者的口语、吐槽与网络化节奏。
- 对话默认采用当代读者可自然朗读的口语句式。时代感优先由物件、钱粮、交通、称呼和社会关系承担，不靠全员文绉绉、整齐对偶或书面判断句制造；只有人物身份、情绪和场景确有需要时才保留旧式说法。严谨人物也应说人话：用具体的否定、追问和行动限制表达证据边界，避免反复像在念审案结论。
- 允许跨时代幽默反差和可复用的角色口头梗，但梗必须来自人物处境或已发生事件，不能在死亡、高压对抗和真相揭露中削弱风险。
- 结尾钩子由本章因果产生，可以安静但必须改变读者对安全、规则或代价的判断。

## 7. 反模板与重复（P1/P2）

- 最近五章不得重复完整长段、累计三次相同长句或明显复制场景顺序。
- 控制破折号和“不是……而是……”；不用整齐列举、四句同构、段末总结制造假深刻。
- 避免固定动作：停步不回头、折纸入怀、守灯到天亮、渡口扔石、眼神变暗等不得成为人物默认反应。
- 避免“这意味着、显然、值得注意的是、命运的齿轮”等作者总结。
- 不按固定感官流水线写每场恐怖；选择最能证明异常的具体证据。

## 8. 单章发布条件

- 规划 JSON 合法，依据 ID 已注册，且存在真实状态变化。
- 正文硬检查无 P1：时代、章号、POV、能力、禁入元素、近期复用均通过。
- 语义审查给出正文中的真实证据，结论为 PASS，且不得推翻静态门禁。
- 正文目标 3200—5000 汉字；2500—8000 为安全范围。低于安全下限不得发布；接近下限时，审查必须确认目标、阻力、选择和余波已被完整演出，不能用凑字数替代场景。
- 任何失败只保留在工作区，不更新正式章节或状态。连续失败达到上限后停止并交由用户判断。

## 9. 开篇追读与盲读者约束（P1/P2）

- 事件开篇必须在同一章内给出主角的眼前目标、第一处可感知的异常、主角推动局势的一次选择，以及由该选择导向的下一步压力。它们不是固定字数配额；若前置铺垫已经无法持续制造问题或压力，应合并或压缩。
- 开篇优先进入正在失败的交易、行动、期限或关系冲突。库存、交通、历史和旧物说明只能随眼前行动抵达；如果一段删去后只损失背景知识，不损失人物、压力、选择或悬念，就不应留在开篇。
- 第一章的核心类型信号原则上在前五分之一内出现，并直接侵入生计、关系或安全；不得先完整写完普通现实戏再切换到灵异主线。
- 早期张洞不得靠未解锁能力、主角光环或现代系统解决问题；其主角性应来自观察、记录、质疑、阻止错误行动、提出可验证办法或承担风险。
- “观察和记录”只有在它促成选择、承担风险或改变别人行动时才构成主角性。关键转折若全由父母、叔公或其他配角完成，张洞只是见证者，本章不得通过人物与追读门禁。
- 核心选择的代价必须在本章落到张洞本人并有可见结果；配角代为误工、损失或承担危险不算兑现。
- 章内核心问题至少发生一次形态变化：获得局部答案、遭遇反例或产生现实后果后，升级为不同且更贴身的问题。连续核对同一物件、门况或解释不算升级。
- 知情角色可保留根源信息，但每次拒绝完整说明时，必须给出至少一项可验证事实、明确代价或可执行限制。只以“别碰”“以后再说”“你不懂”维持悬念，视为谜语人缺陷。
- 每两至三章必须至少兑现一次已建立的问题：获得局部答案、推翻一个假说、取得暂时安全窗口或付出可见代价。不得连续只追加新的诡异物件或隐瞒。
- 发布前增加盲读者审查：审查者只读取本章、必要的既有正文事实和人物卡，不读取大纲、规则真相或作者意图；审查必须确认空间关系、人物目标、日常行为、关键旧式物件的用途与章末行动问题均能从正文自行理解。若读者需替作者补关键设定，结论不得为 PASS。
- 盲读评分以成熟热门悬疑/灵异网文的结构吸引力校准。无漏洞、顺畅和完整只算合格，不能自动通过；开篇拉力、主角所有权、问题升级和章末强迫力均达到强档，且比较结论至少为 `NEAR`，才允许提升。
