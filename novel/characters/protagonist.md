# 张洞 — 主角

## 基本信息
- 姓名：张洞
- 年龄：故事开始时约20岁，结束时约60岁
- 身份：民国时期最强驭鬼者，七老之首
- 出身：双桥镇张氏家族
- 在本篇中的形象：古宅中坐在太师椅上的死气沉沉、满身尸斑的老人

## 性格

### 核心特征
- **绝对理性**: 面对未知先观察再反应，从不行本能之勇
- **领袖气质**: 不怒自威，一句话可以镇住一屋子鬼
- **功利性评估**: 但不冷血——有明确的底线和选择的牺牲对象
- **信息至上**: 所有行为基于已知规则，从不凭"直觉"冒进
- **使命驱动**: 很早就意识到"这不是个人的战斗"，有意识地建立体系

### 专属动作锚点（遮住名字也能认出是他）
- **放杯子**: 开口之前把茶杯放回桌上——放得很慢，杯底碰到桌面没有声音。每用一次灵异力量，杯子放下去的时候手指就多抖一下
- **数步数**: 面对危险时下意识数"它离我几步"——不是在算逃跑距离，是在算"我还能撑多久"
- **看门**: 不管在什么场合，他总会先确认门的位置——不是为了跑，是为了确认"退路还在"

### 独处场景锚点
张洞一个人的时候会擦那把太师椅。
椅子是空的——还没有人坐过。
他用湿布擦扶手，从左到右，擦三遍。
擦完之后他会在椅子旁边站一会儿，看着椅子，像在看一个还没到的人。
没有人知道他在等谁。
他自己可能也不知道。

### 行为逻辑
- 面对新鬼：先退→观察规律→寻找可利用点→以最小代价压制
- 面对其他驭鬼者：评估能力+动机→能合作则约束→不能合作则隔离
- 面对队友：严格但公正，不会牺牲队友换取胜利——但会直说"这次可能要死人"

### 情感表达禁止
- 不直接描述"恐惧""悲伤""愤怒"
- 恐惧 = 沉默片刻后才开口 / 握紧拳头关节发白 / 后退一步
- 愤怒 = 语气骤然变冷 / 一字一顿 / 不再说话直接行动
- 悲伤 = 看着某处很久不动 / 移开视线 / 用行动代替言语

### 情感表达正确示范
```
【恐惧示范】
张洞没有说话。
他看着棺材盖上第三颗钉子松动的方向——往上，不是往外。
叔公的尸体就站在院子里，歪着头，像在听什么。
张洞的手攥着门槛边缘，指甲嵌进木头里。
他没有喊人。他在数——从叔公的脚到祠堂门口，七步。
七步之内，他跑不掉。
七步之外，叔公进不来。
"叔公。"他开口了，声音比平时低了半度，"你活着的时候跟我说过——下面的东西不能动。"
尸体歪着头看他。
"那你现在——是来告诉我怎么动的么？"

【愤怒示范】
张洞把茶杯放回桌上。
这次不是慢慢放的——是放下去的。
杯底磕在桌面上，声音很响。
他没有看罗文松。他看着桌上的碎片——鬼画的碎片。
"放下。"他说。
两个字。没有多余的。
罗文松没有动。
张洞抬眼看他。眼神比平时冷了三度。
"我说——放下。"

【悲伤示范】
张洞蹲在地上，把最后一只钉子敲进棺材里。
锤子放下。
他站起来，没有回头看棺材里的人。
他走了几步，停了。
他没有回头。
但他站了很久——久到罗千以为他不走了。
然后他继续走。
这次没有停。
```

## 能力体系

### 核心灵异能力
- **抹除灵异**: 核心能力——能让厉鬼直接陷入沉睡，抹除一切灵异力量，克制一切驭鬼者。表现为"苍老的手掌抬起，犹如擦灰一样要擦去眼前的污秽"（第1347章）。这是张洞最核心也最恐怖的能力。注意：这不是"鬼域"——不是创造灵异空间，而是**消除**灵异存在本身
- **规则洞察**: 极快的规律识别速度——见过一次就不会再犯同样的错，这是他生存和领导的基础
- **威势压制**: 以盖世威势直接压制灵异——表现为"一句话、一个手势可让厉鬼退散"，这是抹除灵异的外在表现形式
- **灵异感知**: 能远距离感知灵异的存在和大致强度

### 代价
- 身体的逐步侵蚀：从青年→中年→老年，身体被灵异渗透，最终满身尸斑
- 代价的不可逆性：每使用一次抹除灵异，身体就肉眼可见地衰老一截
- 最终的结局：死后厉鬼复苏，尸体独自管理老林（古宅附近的灵异区域），成为古宅禁地的守护者——"张洞这是在死后用自己的尸体管理这片老林"（第1527章）

### 工具与灵异物品
- 古宅（后世的观江小区民国老宅）
- 鬼镜、鬼橱
- 七把太师椅（灵异互通的座位）
