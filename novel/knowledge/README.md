# 创作知识索引

本目录保存写作管道可使用的设定边界，不提供原著全文或大段原文摘录。

## 权威顺序

1. `canon_registry.json`：可信度等级、年代禁入项与硬性事实边界。
2. `../rules/rulebook.md`：正文必须遵守的创作规则。
3. `../state/current.json`：当前章节、人物、时间和伏笔状态。
4. `../characters/`、`../plots/` 与 `../anomalies/`：本项目的人物、事件和异常设计。

## 使用原则

- Planner 根据 registry 和项目设定把核准事实写入规划 JSON。
- Writer 只消费规划、当前状态、规则和风格文件，不直接读取来源语料。
- Reviewer 使用 `canon_registry.json` 和 `rulebook.md` 判定时代串线、设定越界与规则冲突。
- 档案与权威文件冲突时，以权威顺序靠前者为准。
