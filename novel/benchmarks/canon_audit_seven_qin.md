# 《神秘复苏》民国七人与秦老正典审计

## 1. 用途、材料与分级

本报告只校准“前传可以把什么当成原著事实”。主材料为仓库根目录的 `shenmifushu.txt`；行号均指该本地文本当前版本。现有人物卡仅作为冲突检查对象，本报告不替它们背书，也不在本轮修改人物卡、总架构或正文。

事实分为三级：

- **A（原著明确）**：叙述者直接说明、现场直接展示，或由多个独立场景反复确认。
- **B（强暗示／人物推测）**：原著人物根据证据作出的解释，或多条线索高度一致，但文本仍保留“应该、或许、疑似”等余地。
- **不可当正典**：读者推演、同人常用解释或本项目原创。它们并非一律不能写，而是必须作为前传原创，且不能反过来声称“原著早已确认”。

另需注意：白水镇“三年前世界”中的对抗不是一次未经扭曲的历史录像。它会调动人物真实能力和关系，却也受那个异常世界针对杨间的逻辑影响。因此其中展示出的能力可与后续招魂、遗留物互证；具体会面、死亡顺序和台词不能直接当作民国史实。

## 2. 全组先行结论

### 2.1 可以锁死的共同骨架（A）

1. 民国时期存在一支由七名顶尖驭鬼者组成的小队，成员是张洞、罗文松、罗千、李庆之、张伯华、孟小董、张幼红。张伯华在药铺问答中逐一报出六人并承认自己可算第七人；番外又以六人招魂加无法招魂的张洞明确称为“七人小队”。证据：第1304章约128382—128390行；第1607—1609章约155087—155105、155203—155248行。
2. 这七人曾联手平息上一轮灵异，换来不足百年的和平；他们留下的邮局、坟场、古宅、301室、药铺等节点在现代相继衰败。证据：第1422章约140186—140190行；第1304章约128390—128430行；第1512章约146956—146970行。
3. 秦老不是这七人之一。他属于民国出生、被前一代安排或影响的后继人物，承担灵异公交车与下一时代之间的连接。七人名单和番外重聚均不含秦老；秦老另有自己的死亡结局。证据：第1304章约128385行；第1530章约148344—148391行；第1607章约155087—155105行。
4. “七人之死直接同时按下全面复苏开关”不是原著明示。更准确的正典表述是：老一代以自身和设施维持多个节点；随着他们陆续死亡、设施失去管理，厉鬼重新外溢，新的灵异时代到来。证据：第1304章约128390—128430行；第1512章约146956—146970行；第1527章约148145—148153行。

### 2.2 全组尚未给出的内容

原著没有给出七人的出生年、相遇顺序、入队仪式、年轻职业、第一次驾驭厉鬼、能力成长阶梯、日常关系网、统一组织名称、完整终局会议，也没有确认谁制造了全部设施。前传可以补这些空白，但要避免把七人写成从少年时代就分工整齐、理念口号固定的“项目团队”。

## 3. 张洞

### 3.1 A：原著明确事实

| 事实 | 证据 |
| --- | --- |
| 张洞是七人小队的实际核心。白水镇对抗中其余人主动让路，叙述称他为主心骨；战斗中由他带队、承担主力。 | 第1347—1349章，约132960—132981、133127—133166行。 |
| 其核心灵异能使驭鬼者体内灵异沉寂、抹除接近自己的灵异现象；活着时一次出手便使杨间的多种灵异停摆。 | 第1347章，约132966—133008行。 |
| 该能力并不等同于“永久杀死一切真鬼”。原文当场注明他不能抹除真正的厉鬼；更多表现是使灵异消失、显露原形或陷入沉寂。 | 第1347章约132990行；第1528章约148170—148218行。 |
| 张洞是双桥镇人，是张羡光之父；张羡光1942年出生，母亲刘桂、大金乡人，曾在双桥镇小学任教。 | 第1273章约124704行。 |
| 古宅老人就是张洞。主线古宅七日开始时老人刚死，杨间等人为其入殓、出殡并下葬；因此张洞死亡发生在杨间所处时代附近，而非民国中期。 | 第952、957、997章约88923—88950、89514—89555、94750—94762行；姓名确认见第1304章约128385行。 |
| 张洞死后未主动肢解自身灵异，复苏尸体留在古宅，并以尸体压制、管理古宅外老林；闯入古宅的人或鬼都可能遭其袭击。 | 第1527—1528章约148145—148170行。 |
| 古宅能坐落在灵异之地的不同位置；秦老自称曾建议它落在大洲市，以为后辈处理幽灵船留下安排。 | 第1530章约148363—148371行。 |
| 临终前的张洞见门后出现旧队友，会本能地起身前往相助；得知未来有人终结灵异后，他选择不争胜，安心准备后事。 | 第1609章约155246—155274行。 |

### 3.2 B：强暗示与保留项

- **“民国最强”是极强共识，不是官方排行榜。** 张幼红称张洞在驭鬼道路上走到尽头、无人更出色；张伯华认为要称量杨间只能找张洞；杨间也多次把他视为民国巅峰。可安全写成“七人公认的主心骨／最强候选”，不必写成有制度认证的“七老之首”。证据：第1521章约147625—147641行；第1609章约155229—155239行。
- **张洞与孟小董有深厚且带遗憾的私人感情。** 301室保存张洞年轻画像，孟小董预先安排另一个自己参加其葬礼，番外中张洞向“小董”道歉并替她拭泪。爱情关系高度可信，但婚恋性质、为何愧疚、是否曾承诺都没有说明。证据：第1578章约152160—152169行；第1580章约152308—152311行；第1609章约155274—155289行。
- **七把太师椅互通**只是杨间、周登依据“七房、七坟、七椅”作出的推测。现场只找到四把，椅子确有媒介作用，但“七人固定远程会议席”未获确认。证据：第1000章约94924—94938行。
- **张洞将古宅设于大洲市是为了数十年后的幽灵船**是杨间对秦老话语的解释；秦老承认建议选址，却没有完全承认所有细节都是精确预知。证据：第1530章约148363—148371行。

### 3.3 不可当正典的推演

- 1894年前后出生、1911年约17岁、少年木工与账房能力、双桥镇张氏家族旧规，均为本项目前传方案。
- “每使用一次抹除便肉眼衰老数岁”“尸斑就是能力代价”没有原文依据。
- “规则洞察、远程灵异感知、威势压制”是对晚年表现的抽象标签，不是原著确认的独立能力。
- 张洞拥有观江小区鬼镜、鬼橱，没有依据。张洞古宅位于大洲市灵异节点；观江小区民国老宅是另一处建筑。
- 张洞发现秦老、亲自收其为传人，以及把每位队友分配到各自终局节点，均未确认。
- 与罗文松的保守／激进争论、与李庆之至交、把“后事”托给罗千、张伯华公开反对他，均为项目原创关系。
- 张洞为何晚年成婚、与刘桂的具体感情、为何对张羡光隐瞒，原著均未说明。

### 3.4 现有人物卡冲突与过度设定

文件：`novel/characters/protagonist.md`。

- 第59行把“抹除一切”写得过满；应保留第1347章“不能抹除真正厉鬼”的限制。
- 第60—62、65—66行把规则洞察、感知和按次衰老写成确定能力／代价，均无正典证据。
- 第70行把张洞古宅等同观江小区老宅，地点冲突；第71行的鬼镜、鬼橱归属也无依据。
- 第78—84行除“七人队友”外，几乎所有导师、理念、亲疏和托付关系都是原创。
- 第93行“每次出手衰老数岁”再次过度钉死。
- 第99行只有“1942年得子、妻名刘桂”来自原著；“约四十八岁”、长期回避成家、封印初稳等属于前传方案。

### 3.5 前传安全可用空间

- 可原创少年出身、第一次遇鬼、第一只鬼与抹除能力的形成，但不要预先把全部晚年能力写成天赋礼包。
- 可写张洞如何从强者变成主心骨；原著只给出了结果，没有给出领导权形成过程。
- 可写他与刘桂的相识、婚姻和晚年得子，只需锁住张羡光1942年出生及父母籍贯。
- 可把孟小董关系作为重要情感线，但应让“抱歉”的原因到后期才闭合，且不可直接认定二人曾婚约、私奔或有子。
- 可写古宅、老林、太师椅的建立，但鬼镜、鬼橱必须与张洞线分离，除非后续明确标为大胆原创。
- 能力成长可围绕“压制／使灵异沉寂／抹去灵异表现”展开；永久消灭真鬼应保持不可达。

## 4. 罗文松

### 4.1 A：原著明确事实

| 事实 | 证据 |

### 4.2 B：强暗示与保留项

- **“罗文松创建了鬼邮局”未被确认。** 他是第一任管理者，邮局布局也带有其时代痕迹，但第一任管理者仍可能是接管、改造或共同创建者。
- **管理者“在邮局内不会死、离开就会死”来自孙瑞等人的归纳。** 文本支持管理者难以离开、死在邮局外，但不是一条已完整验证的绝对规则。证据：第1061章约102292—102315行；第1347章约132949行。
- **罗文松晚年主动为后人牺牲很多**是杨间根据邮局制度作出的善意判断；中年亡魂与晚年管理者可能有显著性格变化。证据：第1580章约152347—152353行。
- **坠楼是否由张羡光直接策划**没有定论。杨间曾推断第一任管理者被人干掉且源头与张羡光有关，但缺乏现场确认。证据：第1061章约102315行。

### 4.3 不可当正典的推演

- “激进派领袖、赌徒、实验狂、只服张洞”“只有比鬼更像鬼才能赢”均为原创人格标签。
- 罗文松与张洞在鬼画事件争抢碎片、于第七卷决裂，是完整虚构场景。
- 反复拆信、敲柜台、整理亡者信格等动作没有原著来源。
- 与李庆之固定搭档、由李庆之收尾，以及对张幼红身份不安，均未确认。
- “他设计了整个邮局并最终被自己的系统困死”只能作为一种前传解释，不能当原著结论。

### 4.4 现有人物卡冲突与过度设定

文件：`novel/characters/罗文松.md`。

- 第5行“与张洞相仿”无证据；第6行“创建者”超出正典。
- 第12—48行人格、动作、理念冲突和鬼画场景均为原创，却未标原创层级。
- 第60行“管理者在邮局内不会死”最多应列B；第63行“离开邮局就会死”写成绝对规律过满。
- 第65、71—73行把邮局失控归因于他的设计，并钉死多组关系，没有原文支撑。
- 第78行“被困在自己建造的系统里”与原著实际坠楼死亡链条并不等价。

### 4.5 前传安全可用空间

- 可写他为何接管或参与建立邮局、为何选择“让信使冒险筛选管理者”，但“创建者”应当在剧情中作为答案争议，而非开篇档案事实。
- 可从原著中年形象发展出危险、好胜、善于试探又能认输的性格；不必硬套纯粹激进派。
- 可写多种必死规律如何拼成“敲门／开门／关灯”体系，以及他为何最终只留下敲门部分。
- 可写家庭与使命的冲突，因为原著确认其有后代，却几乎没写父子关系。
- 可把张羡光、田晓月与管理权斗争作为晚年悲剧，但凶手和坠楼方式须留出反转余地。

## 5. 罗千

### 5.2 B：强暗示与保留项

- 坟场内大部分老坟应是他关押的厉鬼，但每座坟的来源、数量和是否包含队友遗留都未知。
- 木屋的简陋可支持他晚年生活寡淡，却不能推出他天生沉默、没有活人感情。
- “坟场是七人最终防线”“张洞把后事交给罗千”很适合前传，但原著只确认他看守坟场，没有确认这次正式托付。
- 他的坟土能阻断重启、使死亡固定，可称为“埋葬现在”；不宜扩写成他能随意制定坟场内所有规则。

### 5.3 不可当正典的推演

- 大海市福寿园是现代送信任务涉及的普通墓园，不等同罗千的灵异坟场；把罗千活动地写死为“大海市福寿园”错误。
- 每天擦七块无名碑、第七块背刻“秦”、队友均由他入土，均为原创。
- 控制亡魂与尸体、灵异接触他便自动缓和，不是原著展示的核心能力。
- 每埋一只鬼便失去一部分生命、最终遭坟场反噬，未获确认。
- “不说疑问句、不流露情绪”与原文不符：他会叹息、诧异、冷笑、追问，也会直接讥讽罗文松。
- 与李庆之固定前后排配合、与秦老是长期老搭档，没有足够证据。

### 5.4 现有人物卡冲突与过度设定

文件：`novel/characters/罗千.md`。

- 第5行年龄关系未知；第6、14行把“后事执行者／最深信任”写成事实过满。
- 第7行地点错误；灵异坟场没有被定位为福寿园。

- 第52—54、60—63行的代价、托付和搭档关系无依据。

### 5.5 前传安全可用空间

- 可写坟土、铁锹、棺材钉如何被他组合成坟场体系，以及第一座坟埋了什么。

- 她的正典性格锚是轻佻、自信、爱笑、能承担自己留下的错误；身份焦虑可以作为后世代价，不能倒灌成少年时期唯一人格。

### 10.2 B：强暗示与保留项

- **秦老是人为制造的后继者。** 张羡光称自己调查后确认秦老并非意外，而是民国“老东西”制造，用于前代退场后引导新驭鬼者；这与王小明的母胎实验猜想、秦老“像被设计好”的状态互相印证。但发言者仍是张羡光，制造者名单与方法未出现。证据：第1298章约127709—127722行；第1082章约104409行。
- **生母参与实验**很可能成立，但她是谁、是否自愿、是否驭鬼者、是否生过两个孩子、是否使用中药，完全未知。
- **秦老曾撞死杨间父亲**来自秦老“撞死一个姓杨的人”的暗示、杨间的推断，以及鬼梦中杨孝对老秦与公交车的回忆；整体很强，但具体是直接撞死人、撞鬼导致其计划失败，还是借车处理失控后的杨孝，仍有叙述缝隙。证据：第594章约49121—49146行；第739章约62690—62720行。
- **早期档案说他没有进入民国驭鬼者圈子**，后期却显示他由老一代安排、与七人合作并影响多个系统。最稳妥的解释是官方档案只掌握他童年公开经历，不能用早期一句话否认后期联系。证据：第503章约41204—41210行；后期证据同上。
- 秦老能重启、恢复某些场景与人物的表现很多，但其完整厉鬼拼图从未公布；除“与未来自己对话”外，不宜把所有现象拆成确定技能表。

### 10.3 不可当正典的推演

- 约1910年出生只是方便前传排期的估算，不是原著年份。
- 张洞亲自发现、收养或教导秦老，没有证据；“民国老东西”也不能自动等同七人全体。
- 秦老生母是灵异药品实验者、张伯华曾做其学徒、生母另有一个孩子，均属无来源设定。
- “秦老从不恐惧”“不知道欺负是什么”“五岁捡石头”等人格和童年场景全部原创。
- “禁止秦老主动出手”与原著相反：他会主动调停、组织围杀、驾车接人、封存自己并最终开走幽灵船。
- 公交车驾驶位不是“只能被车选中的人坐”。后文明确可通过与座椅中的鬼建立联系获得驾驶资格；秦老是在寻找合适继任者，而非公交车神授唯一人选。证据：第1395—1396章约137780—137801行。
- 秦老把“杨间”名字传给杨孝、手背浮字、等待名字百年，没有原文依据。
- 张伯华托秦老给罗千送药、路过药铺按喇叭等互动全部原创。
- 他不是“唯一活到最后者”：张洞和张伯华也活到杨间时代附近，且张伯华在秦老退场后仍存活。

### 10.5 前传安全可用空间

- 秦老出生线应采用“双层真相”：公开档案是无名孤儿；暗线是前代人为实验。可以明确实验存在，但制造者、母亲身份与伦理责任应逐步揭开。
- 最稳妥的能力起点是天生死机与“不同时间的自己能对话”；其他重启、探知和规避手段应在事件中逐一表现，不要一次列满。
- 可写他如何获得公交车资格、为何长期运鬼、怎样寻找继任者；驾驶资格须尊重“与座椅中的鬼建立联系”的正典机制。
- 他与七人适合写成被安排的后继者、后期协作者，而不是第八名常驻队员或张洞私人弟子。
- 生母线可以是重大悬念，但不得提前绑定张伯华、药铺或“两个孩子”。

## 12. 前传统一护栏

- 任何人物卡新增条目都应显式标记 `正典A / 正典B / 前传原创`，尤其是能力代价和人物关系。
- 七人可以在后期形成队伍，不能在开篇就自动拥有番外里的默契、立场和终局使命。
- 七人的晚年设施是结果，不等于他们从年轻时就被命运分配为“邮局主、坟场主、药铺主、酒店主”。
- 秦老必须与七人名单分开；他的诞生可以与上一代实验有关，但不要把不明生母改写成已有角色的附属品。
- 张洞、孟小董、罗文松等晚年灵异极强，不代表少年首次驾驭时已拥有完整能力。成长过程是前传最安全、也最重要的原创区。
- 原著刻意保留的谜底——秦母身份、邮局创建者、李庆之坟内之物、孟小董娃娃原料、张幼红第一世拼图、张洞与孟小董的遗憾——应至少保留一层不确定性。
