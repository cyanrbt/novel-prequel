# 王家与“鬼眼之主”正典审计

## 审计用途

- 底本：仓库根目录 shenmifushu.txt。
- 行号：均指当前本地底本；后续若更换文本版本，以章节名为稳定索引。
- A：原著明确叙述、明确展示，或被多处直接事实交叉确认；前传不得改写结果。
- B：人物判断、家族转述或多处线索形成的强暗示；前传可以采用，但不能冒充作者已经钉死的答案。
- 未知：原著没有回答；前传若补写，必须登记为原创推演，并为现代原著的认知断层留下合理原因。

本审计中的“王家诅咒”专指王家亡魂代际继承；“摆钟诅咒”是古宅摆钟对外来者造成的另一套灵异影响，两者不能混为一谈。

## 结论先行

1. 王家适合成为前传的重要平行人物线，但主角应是王家一代夫妇，而不是笼统的“一名王家长辈”。两人都是民国驭鬼者，死后共同成为王家最恐怖的两只亡魂。
2. 王家古宅不是家族诅咒的力量源头。古宅被鬼湖吞没以后，王家诅咒仍传到第四代、第五代；把“住在祖宅”写成继承条件会直接冲突。
3. 全家福能确认家人身份、显示亡魂状态并充当交互媒介，但原著没有确认它创造或维持诅咒。照片、古宅、家规不能写成三个可互换的诅咒载体。
4. 王察灵一生都想终止诅咒，却最终失败，王家延续到第五代。因此前传可以让张洞帮助王家争取一次具体选择，却不能建立一套后来仍有效的“自由退出王家诅咒”机制。
5. “鬼眼之主”不是原著正式称谓。原著明确的对象是弘法寺地下灵异空间里、倒挂在白骨树上并被棺材钉钉住的三至四米高黑影；叙述将它称作鬼眼的原本主人。
6. 鬼眼原主人的姓名、是否曾为活人、与七老的关系、被谁关押以及黑暗之下究竟是什么，原著全部留白。前传可以写一次民国关押行动，但若完整解释其生前身份，就是高强度原创，不应写成七老中某人的隐藏身份。

### 未知项：必须标原创或保留悬念

- 王家一代夫妇的姓名、出生年、职业、家庭出身和最初驾驭的厉鬼。
- 诅咒具体在哪一年、哪一件事件中开启；张洞、七老或其他民国驭鬼者是否在场。
- 诅咒的完整仪式、代价和物理媒介；照片究竟是核心、接口还是后来追加的工具。
- 王家一代如何从活人稳定转化为保留保护倾向的亡魂，为什么不会按普通厉鬼规律立即袭击后代。
- “家人”的精确定义：血缘、婚姻、照片认可、主观认同各自占多少作用；多名子女时谁成为下一代继承人。
- 王家一代各自能力如何分工；为何夫妻协同能把厉鬼直接撕裂并压制。
- 灵异摆钟源头尸体的来历、王家一代获得它的方式，以及白手起家还是在前人遗产上改造。
- 王家大家族其他成员死亡的具体过程，院中棺材为什么不能下葬。
- 王家诅咒是否存在理论上的解除方法。原著只确认王察灵尝试失败，不等于宇宙规则上绝对无解。

### 前传可展开范围

#### 安全且有价值的展开

1. 把王家一代夫妇写成贯穿若干年的平行人物：他们先以保护家人为动机，逐步走到“让历代死者永远保护后代”的极端方案。
2. 展示夫妻之间、创始人与族人之间对诅咒的真实分歧；让反对者拥有合理利益和实际行动，而不是只承担现代价值观发言。
3. 展开王家从大族走向直系五人的过程，并把每次“保护成功”与一次新的继承债绑定。
4. 展开摆钟从被发现、测试到成为古宅时间监狱的过程；源头尸体与完整制造原理可以继续遮蔽。
5. 让张洞参与某次共同关押、见证或反对，但最终只能改变局部伤亡，不能改变王家诅咒和摆钟仍然存在的正典结果。
6. 把全家福用于“谁被算作家人”的恐怖场景，例如活人尚在彩色位置、死者颜色褪去；但规则需要通过行动验证，不由旁白一次讲完。

#### 必须留白或严格限写

1. 不把古宅写成诅咒电池、亡魂不能离开的固定守位点，或房毁咒灭的核心。
2. 不让张洞、罗文松或人皮纸成为王家诅咒的制造者；至多提供过一个被王家改造成最终方案的局部条件。
3. 不给王家建立后世仍有效的自由退出制度。若出现“退出”，只能是诅咒开启前的拒绝、某个旁支退出，或一次失败／被撤销的局部选择。
4. 不把1910—1920年代的王家人物误写成王陆夫妇的成年时代；这个阶段优先使用王家一代及其同辈。
5. 不提前写死王家一代“终结整个灵异时代”的宏大目的；那是杨间的推测，不是创始人亲口留下的遗言。

## 二、“鬼眼之主”正典审计

说明：第1340章发生在灵异构建的“过去世界”，可用于交叉印证对象形态与第二只鬼眼，不宜单独拿来证明现实历史中另有一次事件。

### B级：强暗示、人物推测

| 编号 | 强暗示／推测 | 证据性质 | 使用边界 |

### 未知项：原著完全没有钉死

- 高大黑影的姓名、性别、出生年代、是否曾是活人或驭鬼者。
- “原主人”是指创造鬼眼者、曾经驾驭鬼眼的人，还是鬼眼所属完整厉鬼的主体。
- 它是否与张洞、七老、秦老、王家或其他民国势力见过面。
- 谁用棺材钉关押了它，谁修建弘法寺地下室，寺庙看守传承为何丢失姓名。
- 白骨树、人皮、布条、干尸头、纸幡、高大黑影和鬼眼之间到底是一个整体、数只鬼还是一次人为拼合。
- 人形黑暗下方究竟覆盖着尸体、棺椁、另一只鬼或空无一物。
- 原主人为何只显露一只眼；杨间长出九只／逼近十只的机制是否也是原主人完整形态的一部分。
- 被钉时是否仍保留活人意识，为何眼被取走和棺材钉被拔出后没有立刻袭击杨间。
- 高大黑影在现代消失后的去向和结局。

### 前传可展开范围

#### 低风险方案：只写关押，不写身份答案

这是最稳妥的方案。前传可以完整呈现：有人发现一只红眼造成的空间错位；多人付出代价把黑暗中的高大对象钉到白骨树；在弘法寺地下修建隔离空间；把看守责任交给不理解全部真相的后人。镜头始终不揭开黑暗，也不确认白骨树和黑影各自是什么。

该方案仍能产生两层恍然大悟：读者会认出杨间第一只鬼眼和饿死鬼棺材钉的旧现场，也会意识到现代“偶然获得鬼眼”建立在民国某次失败封印留下的缝隙上。

#### 中风险方案：原创一名独立的前身

可以原创一名七老之外的驭鬼者，使其在失控或拼图补全后成为高大黑影；但必须满足以下结果：

1. 此人最终不再能以正常身份被辨认，现代只能看见黑暗外壳。
2. 不属于七老中的任何一人，不挪用他们已有的现代结局。
3. 张洞可以参与关押，但不能制造鬼眼、预知杨间或把鬼眼安排给后世主角。
4. 形成过程不能解释掉白骨树下方所有未知；至少保留“人是否还在黑暗里”这一层。
5. 全部身份与过程在项目正典表登记为C级，而不是A/B级。

#### 高风险且不建议的写法

- 把鬼眼原主人写成张洞、秦老、罗文松或其他已知七老的隐藏形态。
- 让王家一代制造鬼眼，或把王家诅咒、灵异摆钟、人皮纸和鬼眼强行并成同一实验。
- 把弘法寺地下室建造时间等同于鬼眼诞生时间。
- 写成张洞精确预见杨间会取得鬼眼，因此故意留下眼睛和棺材钉。
- 在前传中公布高大黑影逃脱后的现代结局，覆盖原著保留的未知。

## 三、现有项目文件冲突与缺口

### novel/plots/event_王家.md

1. “一名王家长辈”过度单人化。正典创始层是王家一代夫妇；若故事只跟随其中一人，必须持续保留另一人的共同决策与最终亡魂位置。
2. “以受影响的照片、祖宅或家规维持保护”把三种性质不同的事物混成可替换机制：
   - 全家福：有直接交互和家族认证证据；
   - 古宅：时间监狱，且被沉入鬼湖后诅咒继续；
   - 家规：社会压力，不是已证实灵异载体。
3. “退出权”若指解除整个诅咒，会与王察灵失败及第四、第五代延续冲突。可以改成诅咒开启前的拒绝权、旁支退出权，或一次没能传到后世的局部选择。
4. “固定守位”可以保留为主题类比，不能当作王家亡魂的实际行动规则；四只亡魂会离开古宅、进入照片、寄居身体并跟随王察灵行动。
5. “不能彻底解除或创造后世完整体系”的边界是正确的，应继续保留。

### novel/plots/event_2.md

- 把王家控制为中型人物事件、本卷不解释所有祖宅鬼来源，是合理克制。
- 但第二卷主要年份为1914—1927，若启用王家线，应明确出场者是王家一代或其同辈，而不是成年王陆夫妇。
- 若只做一次“保护也会变成继承债”的案例，应把王家诅咒最终落成放到后卷或卷外；否则一个中型事件很难承载夫妇选择、大家族衰败、摆钟和照片四条线。

### novel/plots/event_8.md 与 series_architecture.md

- event_8规定“若前卷没有成为人物主线，终卷不临时补写鬼眼之主、王家诅咒大段起源”，这条边界正确。
- 总架构只完整锁定人皮纸为核心后世器物，并要求全书只完整形成两至三项著名遗产。王家与鬼眼若同时升格，会挤占剩余名额；应二选一成为完整起源，另一条只写关键接触或表层关押。
- 总架构目前没有王家一代夫妇、王家诅咒或鬼眼原主人的正典条目，后续应先把本审计结论录入 canon_registry，再决定是否升格剧情，不宜直接开始章节设计。

### 人物卡与知识库缺口

- 当前 novel/characters 下没有王家一代夫妇、王陆夫妇或“鬼眼之主”人物卡，这避免了现成硬冲突，但也意味着任何姓名、能力拆分和年龄都尚未获项目授权。
- 当前 canon_registry 也没有王家和鬼眼条目。后续至少需要登记：王家一代为夫妇、古宅非诅咒源头、王陆时代、亡魂传承机制、“鬼眼之主”非原著专名、弘法寺地下室仅能锚定到民国。

## 四、建议的创作取舍

在“人皮纸已经是核心器物”的现有总架构下，建议采用以下优先级：

1. 王家升格为重要人物支线。它与全书“保护是否变成替后人决定”高度同构，而且有明确的民国人物、现代结果和代际反驳。
2. 鬼眼线采用“完整写关押、拒绝写身份终解”的低风险方案。这样既能兑现原著伏笔，又不把全书变成张洞经手全部著名灵异物品。
3. 王家一代应与张洞有合作和理念冲突，但不是张洞队伍成员；张洞救下一次当下的人，王家一代则把这次有限成功推演成世代亡魂方案。
4. 前传结束王家阶段时，读者应明确知道他们为何做出选择，却仍不知道诅咒的全部技术原理。结束鬼眼阶段时，读者应知道是谁付出代价完成关押，却仍看不见黑暗下面的本体。

这样可以形成两种不同的“恍然大悟”：王家线回答“为什么后代会被爱变成的诅咒守护”，鬼眼线回答“杨间开局捡到的力量为什么会被留在那扇门后”，同时不宣称前传拥有原著所有谜底。
