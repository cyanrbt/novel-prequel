# 《记忆中的父亲》同剧情试读本 V1

> 非正式文风校准稿。取材范围为原著第25—26章：电话档案否定父亲存在、记忆污染被识破、染血报纸袭击、杨间借鬼眼脱身，以及屋内之物取得他的脸。保留主要事件与揭示顺序，不复制原句。

## 试读正文

电脑屏幕上是一篇国外论文，翻译得不太通顺。

杨间刚看到“黄金不受影响”那一段，床边的卫星电话响了。

是周正留下的那部。

他接起来，眼睛还停在屏幕上：“哪位？”

“你还问我哪位？”电话里的女孩像是忍了很久，“张伟同学，我们把你从出生到现在查了一遍，最后发现你根本不叫张伟。”

“查得挺快。”

“杨间，十九岁，大昌市人。需要我把身份证号码也念给你听吗？”

“不用，剩下的我自己知道。”杨间把网页往下拉，“一开始接到陌生电话，我总不能你问什么就答什么。万一你们是骗子呢？”

“因为你一句假话，我们白跑了多少地方？”

刘小雨越说越快，后面已经带上了工作纪律和保密规定。杨间把手机稍微拿远了些。

卧室门这时开了。

一个中年男人从客厅进来，手里拿着报纸，在床沿坐下。报纸展开以后挡住了脸。

杨间顺手把床边的充电线拨开，免得被他坐住。

这个动作做完，他自己也没觉得有什么。父亲晚上喜欢拿份报纸坐一会儿，家里一直是这样。

电话里还在说。

“有关灵异事件的内容不能告诉无关人员。尤其是家人，他们没有处理能力，知道以后只会——”

“我爸就在旁边，你小声点。”杨间说，“今天先这样。”

电话那头突然停了。

“你说谁？”

“我爸。”

“先别挂。”刘小雨的语气整个变了，“你确定旁边的人是你父亲？”

杨间看了一眼床沿。男人坐得很直，报纸一动不动。

“不然呢？”

“我手边就是你的档案。你父亲在你小学五年级那年死于车祸，之后你的监护人一直是你母亲。档案里也没有再婚记录。”

杨间盯着电脑上的那行字，没有立刻听明白。

“你查错人了。”

“姓名、住址、出生日期、学校，全对。杨间，你家里可能已经出事了。现在别碰那个人，马上离开。”

“我爸昨天还——”

他说到一半停住了。

昨天父亲做过什么？

应该吃过晚饭，也应该在客厅看报。可桌上摆了什么菜，父亲有没有和他说话，几点回的房间，他一件也想不起来。

这种想不起来原本没什么。谁会专门记住家里每天发生的小事。

可电话里的人正在告诉他，这些日子根本不存在。

杨间慢慢转过椅子。

卧室没开灯，光都来自电脑。男人坐在离屏幕几步远的床沿，报纸上的字黑成一片，这个距离和亮度，根本看不清内容。

纸也没有响过。

从他登录网站到现在，客厅里似乎一直有个人在看报。那个人是什么时候走进卧室的，杨间竟然没有印象。

“爸。”

男人没有应声。

杨间伸出手，想把挡脸的报纸拨开。手刚抬到一半，他看见衣柜侧面挂着一个黑框。

那是一张遗照。

照片里的人比床边的男人年轻一些，眉眼却一样。黑框下还压着一小截褪色的白布。

杨间的手停在报纸前。

他每天进出这间房，为什么直到现在才看见这张照片？

不，也许他看见过。

只是每次看过去，脑子里都会自然而然地绕开一个问题：照片上的人是谁？

“杨间，回话。”手机里传来刘小雨的声音，“你是不是还在房间？”

“在。”

“出去，先出去再说。”

杨间收回手，拿起桌上的手机，站了起来。

档案可能出错。电话也可能是有人故意骗他。甚至眼前只是做梦，他还趴在学校的课桌上没有醒。

但这些解释都不值得他拿命去赌。

他往卧室门口退，视线始终没有离开床边。男人没有追，也没有放下报纸，仿佛根本没发现房里少了个人。

杨间退到门边，角度变了，报纸背面露出一块深色。

开始只有巴掌大。

很快，那片颜色沿着纸纤维往外浸，暗红、黏稠，边缘湿得发亮。男人的手指压在红色里，还是一动不动。

这不是油墨。

杨间跨出卧室。

身后传来纸张折动的轻响。

他回头看了一眼。

男人仍坐在床边，脑袋却已经转了过来，脸正对着门口。那张报纸还举在胸前，不再遮脸。

报纸后面没有父亲。

那颗头上只有一层平整发白的皮，没有眼窝，没有鼻梁，也没有嘴。刚才照片里熟悉的眉眼，一样都找不到。

杨间转身就走。

才迈出一步，眼前忽然一暗。

一张湿冷的纸迎面贴了上来，血腥味堵住口鼻。它贴得没有一点缝，像有人用两只手从后面把他的整张脸严严实实按住。

杨间抓住纸边往下扯。

脸上的皮肉跟着被拉动，疼得他手指一松。纸不是贴在脸上，倒像已经长进了肉里。他张不开嘴，鼻子也吸不进气，胸口很快憋出一阵闷痛。

电话掉在客厅地上，刘小雨还在里面喊他的名字。

普通的手扯不开。

杨间抬起右手。手背的皮肤向两边撑开，一只发红的眼睛从里面露了出来。

这只手再次抓住报纸。

纸面终于被掀起一点，凉气从缝里钻进来。可身后立刻传来一股力量，又把它按了回去。黏湿的纸越收越紧，他耳边只剩下自己越来越快的心跳。

只有鬼能碰到鬼。

杨间不再省着那点力量。

额头的皮肉顶起，报纸上随即裂开一道口子；脸颊又睁开一只眼，湿纸被从里面硬生生撑破。每多睁开一只眼睛，勒在脸上的力量就松一点。

他趁机攥紧纸边，猛地往下一撕。

染血的报纸碎成几片，落在地上。

空气一下灌进喉咙。杨间弯腰咳了两声，没有回头去找那个男人。他抓起掉在地上的电话，撞开大门跑了出去，连电脑都没关。

楼道里的声控灯被脚步惊亮，一层接一层往下。

屋门在他身后敞着。

房间里重新安静下来。

过了一会儿，那个没有脸的男人从卧室走到客厅。它弯下腰，把地上的报纸碎片一张张捡起来，按回原来的位置。

纸上的裂口慢慢合拢，暗红色也重新连成一片。

男人拿着报纸回到沙发前坐下，举起手，继续保持看报的姿势。

几个小时后，它把报纸放了下来。

那张空白的脸已经有了五官。

眉毛、鼻梁、嘴唇，连耳侧的轮廓都和杨间一样。只有本该长着鬼眼的几个位置仍是空的，像一张照片被挖走了几小块。
