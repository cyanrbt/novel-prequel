# 文风校准样本轮换协议

## 目的

同剧情试写用于拆解原著及同类型优秀网文的高层叙事机制，不用于反复优化同一个场面。连续使用论坛体会让系统只学会楼层、回帖、断更和刷新，而无法证明这些经验能够迁移到家庭、群像、行动或规则场景。

## 强制轮换规则

1. 相邻两轮不得使用同一种叙事媒介或场景发动机。
2. 新样本与上一样本至少在以下五项中的两项不同：视角载体、人物数量、空间形态、冲突方式、节奏任务。
3. 同一原著章节只允许连续迭代到一个稳定版本；回归审查结束后必须换样本。旧样本以后可以复测，但不能占据下一轮。
4. 论坛、书信、档案、电话、笔记等媒介技巧只先记为局部经验；至少在两种非同构场景中再次成立，才能提升为全局文风规则。
5. 每个候选在审查前冻结路径与 SHA-256。sub agent 只读正文和对应原著片段，不先读作者复盘或其他审查意见。
6. 每轮至少覆盖三个相互独立的维度：人物与声纹、叙述与节奏、逆向挑错与同剧情核对。修订版必须重新审查，旧报告不自动续用。
7. 原著的具体句子、专有意象、网络梗和动作编排不进入全局提示；只记录信息顺序、认知边界、情绪波形与人物选择等可迁移机制。

## 经验晋级规则

- `LOCAL`：只被一个样本证明，例如“论坛关键回复直接落页”。只能用于相同媒介。
- `CANDIDATE`：在两个不同样本中都改善真人或独立审读体验，例如“不要让叙述者重复解释已经展示的异常”。可以进入候选提示，但必须保留反例检查。
- `GLOBAL`：至少跨三个不同场景成立，且没有造成剧情、视角或节奏退化。才允许写入全局文风约束。
- 任一经验若在新样本中促成整齐模板、角色同声或信息提前，立即降级，不以此前评分维护它。

评分、段长和词频只用于发现差异。最终证据仍是冻结正文、原著对照、独立 sub agent 报告与真人实际读感。

## 第03轮迁移结果

第84—85章“门外徘徊者”已完成V1—V2。V1证明听觉路线和瘫痪动作可以比原著更清楚，也暴露出论坛样本的隐藏过拟合：逐条帖子信息被换成逐声假说，媒介变了，叙事仍像整齐的信息阶梯。

V2通过恢复白天讨价还价、无用家常、人物窝火和被打断的判断，修复该问题。三名独立审读回归评分为8.2、8.9、8.0，均未发现P1；V2冻结为“听觉空间／行动受限／临场假说”的阶段性基线，不继续开V3。

本轮后经验级别调整如下：

- `GLOBAL`：证据已经直接展示时，不立即让旁白复述；每项关键信息必须能追溯到人物感知、媒介来源或明确视角切换。两项均已跨论坛、家庭记忆、听觉徘徊三类样本验证。
- `CANDIDATE`：连续场景不能机械地每事实一段；危险推断应夹带人物私利、脾气、错误希望和未完成念头。前者已跨两类非同构连续场景，后者仍需群像复测。
- `LOCAL`：白天生活温差、瘫痪失败动作、人皮纸限知切镜只适用于本轮或同构场景，不进入全局提示。

下一轮必须转入第401—402章密闭交通工具群像，测试多人声纹、共同风险、信息分配和不可逆后果，不再围绕单人黑屋继续优化。
