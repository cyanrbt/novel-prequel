# 《借宿》同剧情试读本 V2

## 试读正文

白天那阵咳嗽，是在村后一栋废屋旁边听见的。

声音几乎贴着后颈，病得只剩半口气的人才会那么咳。杨间和张韩一起回头，土路上却没人。张韩绕去屋后，杨间抬脚踹开虚掩的木门，屋里堆着几件落灰的农具，连藏人的地方都没有。

两人又找了一圈，什么也没找到。

“别一有动静就往鬼身上想。”杨间退出屋子，“村里最不缺的就是老人，可能从墙后过去了。”

这话是说给张韩听的，也省得自己在一声咳嗽上浪费时间。可村口那场丧事又解释不通。灵堂搭起来了，棺材也停着，村里却像没人关心死的是谁。

傍晚，杨间在菜地里拦住刘根荣。

“大爷，打听几个事。”

刘根荣蹲着栽菜苗，头也不抬：“没空。”

“我还没问。”

“问了也没空。”

杨间在旁边站了一会儿，从口袋里抽出一百块：“三个问题。”

老人这才抬头。他把手上的泥往裤腿一抹，菜苗也不要了，过来接钱的动作一点不像六十多岁。

村里平时就这么冷清，年轻人大多搬去了城里；最近没出过怪事；村口办丧事的那个人，他不认识，也不是村里常见的人。三句话答完，刘根荣把钱折好塞进内袋，又回去捡他的菜苗。

“那村里闹没闹过鬼？”杨间问。

刘根荣朝他摊开泥手：“第四个了。”

杨间看了他两秒，又递过去一张。

“年年都有人说，反正我没见过。”老人收了钱，语气重新和气起来，“你们城里孩子现在就爱听这个？”

有用的话没问到，钱倒花出去两百。杨间往村口看了一眼，天已经快黑了，只能问他附近有没有地方住。

“我家，一百一晚。”

刘根荣做生意很快。

二楼空着的房原来是他小儿子的。两个儿子都在大昌市买了房，只有过年才回来；老伴去年也走了，现在屋里就剩他一个人。老人领杨间上楼时把这些事来回说了两遍，又嫌城里的房子小，阳台连菜都种不了。

楼梯口有两扇相对的门。刘根荣指左边给杨间，自己住右边。房里床挨着里墙，床尾正对一只旧衣柜。柜里还有一床没人晒的被子，潮气很重，杨间没有动它。

他把背包、焊死的金盒和卷好的人皮纸一起放进去，另拿衣服压在上面。柜门有点歪，关到最后得用膝盖顶一下。

“夜里别喊我，喊了也听不见。”刘根荣站在对面门口说。说完，他又下楼去了。

睡觉前，杨间把自己的门带严，没有上锁。一楼传来两道门闩相碰的声音，之后是老人拖鞋上楼的响动。对门开合了一次，整栋房子这才静下来。

杨间只打算住三天。三天里没有情况，他就回大昌市，找把消息卖给俱乐部的那家公司算账。至于村里的鬼愿不愿意露面，他管不了。

半夜，他醒了一次。

意识先醒，身体没醒。肩膀、手臂和两条腿像被压进床里，手背下的鬼眼却还在动，争着接管这副身体。

这种瘫痪每天夜里都会来，短则一个小时，长的时候接近两个小时。平时熬过去就行，今晚却选得真准。

杨间试着屈右手食指。指腹贴着床单，半点知觉也没有。他只能把眼睛往门边转，勉强看见一点门的轮廓。

楼下响起两声咳嗽。很轻，前一声像没咳出来，后一声才拖开。

他的眼睛不动了。

白天废屋后面，就是这个声音。

刘根荣半夜下楼了？这个念头还没过去，一楼便落下一记沉重的脚步。没有对门打开的声音，也没有楼下门闩被抽开的声音。

第二步落得更近。人已经在屋里走动。

“真会挑时候。”

杨间只在心里骂了一句。白天在村里转了一圈，它不出来；偏偏等他瘫在别人床上，连翻身都做不到，脚步来了。

那东西在空着的一楼走了几步，进了楼梯间。木梯一阶一阶地响起来，每一步之间都有停顿，不急，却没有停下来的意思。

杨间盯着房门，指尖还在暗暗使力。门是关着的，却没上锁。当时只是图进出方便，谁知道方便了谁。

脚步上完最后一阶，在二楼过道里停住。

两间房，刘根荣一间，他一间。随便挑的话，他还有一半机会。就怕这东西不是上来串门的。

杨间想喊对门的老人，气刚送到喉咙又压了回去。现在喊人，除了告诉外面这间房里有个活的，未必有别的用。

脚步重新动了，在狭窄的过道里走出几步，又折回来。它没有敲门，只来回走，偶尔停上一阵。那阵虚弱的咳嗽再次响起时，杨间背后的衣服已经被汗贴住。

过了好一会儿，两扇门都没有被推开。

也许它还没找到要找的人。杨间甚至觉得今晚的运气没有坏到底，可学校里那只隔着门找人的鬼偏在这时候冒进脑子。他盯着门的黑影，想起黄岗村还有这么多活人，又觉得门外这只至少不是咳一声就能把人全杀了。

这个念头没来得及往下想，过道上的脚步消失了。

它没有走下楼。只是停在二楼某个地方，咳嗽也跟着停了。

杨间的眼睛盯得发酸，泪水积在眼角。随后左侧响起一声细长的摩擦，门轴动了。

门缝慢慢宽起来。外面没有光，一道黑影在门口站了片刻，头顶几乎挨着门框，肩膀把入口堵去大半。

肯定不是刘根荣。

它走进来，地板随脚步微微下沉，再发出迟一些的吱响。潮湿的腐臭也进了屋，像有东西烂在一只封了很久的袋子里。

脚步停在床头附近。

杨间看不清它的脸，也不知道它是不是正看着自己。他能做的只有躺着。对方若是来杀他，早该动手了，停在这里算什么？等他能动，还是等他不能动？

冷汗流进右眼，刺得发疼。他借着这点疼又催了一次手指，床单还是平的。

如果这只是鬼奴，村里就还藏着一个能放出鬼奴的源头。杨间想到这里便不再想了。真到那个级别，他活过今晚就走，这件事爱谁处理谁处理。

床边的脚步又动起来，没有继续靠近，而是绕过床尾。旧衣柜被拉开，歪斜的合页涩了一下，忽然弹响。

杨间看不见柜子里面。他先想到背包里的钱和卫星电话：会不会是俱乐部那几个人趁他不能动来抢东西？这猜法蠢了点，可对面若真是个能谈条件的活人，已经算是今晚最好的消息。

金属的震响从柜里传出来，余音贴着木板嗡嗡作响。紧接着又是一下。

不是背包。

它在砸那只装着无头鬼影的金盒。

杨间这回真有点慌了。他把全部力气逼向右臂，肩膀深处很快撕扯般疼起来，手肘却连床都没离开。

又一下。

金盒只要裂开一道缝，无头鬼影就能脱困。那东西会夺取人的身体，也会寻找适合自己的灵异部件；如果它拿走杨间的身体，再得到鬼眼，便等于连鬼域一起拿走。到时候死的不会只有这间屋里的人。

敲击还在继续，力道没有变化。杨间不知道盒盖凹到了什么程度。可能还能撑很多下，也可能下一下就开。

“动啊。”

他的牙关咬得发疼，右臂依然没有知觉。皮下的鬼眼自行转动，阴冷一阵阵往骨头里钻，根本没有把身体还给他的意思。

金属声再次落下。

在杨间看不见的衣柜里，人皮纸从衣服下面慢慢滑出来，越过隔板边缘，落在已经凹陷的金盒上。纸张贴住盒盖以后，原本举起的东西停在半空，没有再砸下去。

杨间只听见敲击停了。

“停了？”

他等着下一声。没有。

为什么停？

盒子已经开了？

屋里没有脚步，也没有咳嗽。杨间盯着衣柜所在的黑暗，身体仍然一动不能动。

如果盒子真开了，无头鬼影现在就在他的床边。
