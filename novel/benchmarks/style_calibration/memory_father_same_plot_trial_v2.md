# 《屋里的人》同剧情试读本 V2

## 试读正文

杨间在电脑前坐了一个多小时。

网页上列着各种灵异事件，按伤亡和扩散范围分了等级，下面还有一张所谓的全球危险榜。写榜单的人把名字、特征、死亡人数列得明明白白，解决办法那一栏却十有八九空着。

“排得这么整齐，不还是碰上就死。”

他关掉榜单，又打开一篇谈黄金的论文。机翻把好几句话弄得前后颠倒，他只能一行一行猜。

看了没多久，杨间起身去了厕所。

客厅没有开灯。父亲坐在沙发上，报纸举在面前，借着卧室漏出来的一点电脑光看字。

“爸，你这样看报不嫌累眼睛？”

沙发上的人没答。

杨间从他脚边绕过去，顺便把踢散的拖鞋往沙发底下拨了拨。他在厕所洗完手，回来时父亲仍保持原来的姿势。

“睡着了就回房睡。”

还是没有声音。

杨间急着把能找到的资料看完，没有站在那里等。他回到卧室，在靠门的书桌前坐下，重新翻那篇论文。

页面刚拉到“黄金”两个字，床头那部卫星电话响了。

“哪位？”杨间接起电话，另一只手还握着鼠标。

“张伟同学，你挺能装啊。”刘小雨的声音绷得发紧，“我们把张伟找到了。他说自己根本没拿过这部电话，也不认识什么周正。”

“那你们总算找对人了。”

“你叫杨间，大昌市人，十九岁。还要我继续念吗？”

“不用。第一次接到陌生电话，总得留一手。你问什么我就说什么，哪天被骗去卖了还替你们数钱？”

“就因为你留这一手，我们白查了多少东西？总部每天要处理的不只你一个人的事。你既然拿了周正的电话，之后就必须——”

父亲从客厅走了进来。

杨间余光看见他到了床边，便把散在床沿的充电线和校服一起捞开，腾出一块地方。

男人坐下，依旧举着那份报纸。

“爸，找我有事？”

没有回答。

杨间早习惯了家里人各做各的，转头又对电话说：“你先讲重点。我又不是你们的人，规章制度背给我也没用。”

“你旁边还有人？”

“我爸。”

电话里安静了一瞬。

“先别挂。”刘小雨说，“你刚才说的是谁？”

“我爸。怎么了？”

“我正在看你的档案。你父亲在你小学五年级时遇到车祸，已经去世很多年。之后你的监护人一直是你母亲，档案里也没有她再婚的记录。”

杨间按着鼠标滚轮的手没有松。网页从论文中间一直滑到底部，他却没看屏幕。

“你们档案弄错了。”

“名字、生日、住址和学校全都一致。杨间，别再和旁边的人说话，先离开屋子。”

“我爸刚才还在客厅——”

后半句话卡住了。

这句话本来是要证明刘小雨查错了，可父亲坐在客厅看报，和父亲早已去世，似乎根本没有在他脑子里撞到一起。直到电话那边指出来，他才第一次觉得两件事不能同时是真的。

书桌在门边，床靠着里面的墙。父亲刚才还离他很远，现在却坐在床沿，和在客厅时一样直着背。几分钟过去，报纸没有翻页，也没有发出过一次折动的声音。

卧室没开灯，屏幕的光照不到报纸正面。

杨间转头时，椅脚在地砖上刮出一声。他这才发现自己连椅子一起往门边挪了半步。

“爸？”

男人没有动。

杨间的视线越过报纸，在床旁的柜子上停住。那里挂着一个黑框，照片中的中年男人眉眼清楚，黑框下还留着一截褪色白布。

遗照上的人正是父亲。

杨间握电话的手紧了一下。小学五年级那几个字像在哪听过，可他越想，脑子里越空。床边的人却熟悉得不需要回忆，仿佛只要父亲坐在那里，一切就理所当然。

“杨间，你还在吗？”

“在。”

“马上走，不要碰他。”

档案也许会错，但柜上的遗照不会无缘无故挂在这里。杨间把手机换到左手，慢慢站起来；椅背碰上墙，他没有回头扶。

他离门只有一步，床边的男人没有挡路。杨间面朝着对方往外退，鞋跟先越过门槛，接着是整个身体。

就在角度变化时，他看见报纸背面多了一片暗红。那片颜色从男人手指下面渗出来，沿纸纹慢慢散开，越过折痕后仍没有停，湿亮得像刚从血里捞出来。

电话中，刘小雨还在催他下楼。

男人手里的报纸向下落了半寸，露出额头。杨间盯着那里，没有再退。

下一刻，那颗脑袋转向门口。

报纸后是一张空脸。皮肤从额头一直连到下巴，没有眼睛、鼻子和嘴，连一点凹陷都没有。

杨间立即转身。

男人的手指在这时松开。染红的报纸没有落地，而是一下展开，贴着床沿掠过卧室，越过门口剩下的两步距离。

杨间只来得及偏了一下头，湿冷的纸已经盖住整张脸。

他被撞得退进客厅，后腰磕在茶几边。纸面贴住口鼻，血腥味直往喉咙里钻。他抓住下沿往外揭，脸上的皮肉也跟着被扯起，像纸已经和皮肤黏成了一层。

报纸的另一面仍有力量从卧室方向往回拉。杨间一手撑住门框，身体却被拽得向前，鼻子吸不进气，张嘴也只咬到一股又湿又腥的味道。

普通人的手碰不到这种东西。学校里的经历已经证明过，可动用身体里的鬼同样是在催它复苏；周正那副快被鬼掏空的样子，就是最后会变成什么。

杨间没有多少时间选。

他右手手背裂开，一只发红的眼睛从皮肉下转了出来。那只手重新扣住报纸边缘，湿纸终于被揭开一道缝，他猛吸进半口气。

卧室里的拉力骤然加重，缝隙重新合上，杨间的额头撞在门框上。皮下其余的眼睛像被惊醒一样转动起来，冰冷的躁意沿着脸颊往上爬。

再借一分力量，身体里的鬼就会多醒一分；不借，他连下一口气都没有。

额头的皮肤向外鼓起，第二只鬼眼顶破了报纸。裂口刚出现，脸颊上的第三只眼睛也睁开，湿纸从里面接连崩开。

拉住他的力量还没有消失。杨间趁着口鼻露出来，右手抓紧几道裂口同时往下扯，终于把整张报纸撕成碎片。

碎纸落在卧室门内外。杨间弯腰喘了两口气，抓起掉在茶几旁的电话，直接冲向大门。他没有去拿电脑，也没有再看床边一眼。

门被撞开，楼道里的声控灯随着脚步一层层亮下去。

屋里安静了很久。

没有脸的男人从卧室走出来，在门口蹲下，把散在两边的纸片捡到一起。它按住裂口，纸纤维缓慢交叠，最后又拼成了一张完整的暗红报纸。

原本只有血污的纸面上，多出了一张人脸的轮廓。

是杨间的脸。

男人拿着报纸回到沙发前，仍坐在最初的位置。它把那张带有人脸的报纸举在面前，身体慢慢没进没有开灯的客厅。

几个小时后，报纸被放了下来。

那张空白的脸已经变成杨间的模样，眉骨、鼻梁和嘴唇没有差别。唯独杨间长出过鬼眼的地方仍然缺着，像一张照片被剪走了几块。
