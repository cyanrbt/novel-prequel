# Claude 修复后补盲测结论

## 结论先行

Claude 修复有效，而且两款模型都进入了第一梯队。四位有效裁判虽然对前四名的内部次序看法不同，但无一例外都把 Luna、Sol、Claude Opus、Claude Sonnet 排在前四；第五名与第四名的均分又相差 8.75 分。因此，本轮最可靠的结论不是某个模型以零点几分“夺冠”，而是第一梯队已经从首轮的 Luna、Sol 扩展为四个各有侧重的可用模型。

这并不推翻首轮的默认路线：`gpt-5.6-luna / max` 仍适合常规正文，`gpt-5.6-sol / xhigh` 仍适合结构、设定和关键因果把关。Claude 的价值主要是补上两种此前较弱的能力：Opus 的具体生活质地和自然叙事，Sonnet 的粗粝口语感与“像人在现场写”的网络生命力。

## 两款 Claude 分别好在哪里

### Claude Opus 4.6 Thinking

Opus 的优势不是更华丽，而是会用普通动作和器物把人物钉在现场：犹豫通过反复拿出又收回手机呈现，老师的职业习惯通过没收手机、催交练习和处理门锁呈现。它较少把惊恐直接命名，也不会急着把杨间的推断升级成确定规则。这让正文有一种已经生活过、而不是刚从剧情清单展开的感觉。

七维上，Opus 的网络生命力为 13.25、反模板为 8.50，均明显高于 Sol；空间清晰度仍有 9.00，说明它并不是只会润色气氛。问题在剧情节拍：一位裁判认为它在王老师出门和学生死亡前增加了过多轮敲门，改变了冻结的因果节奏；同一位裁判还指出电话里“强行动用厉鬼可能引发第二起异常”的警告没有被明确保留。其 3662 个汉字也比要求上限多 62 字。

因此，Opus 更适合关键章节的深度试写、人物生活质地补写和文风修订，不宜在没有剧情校验的情况下单独担任最终定稿模型。

### Claude Sonnet 4.6 Thinking

Sonnet 的网络生命力为 14.25、反模板为 8.75，两个维度都是全组最高。它的句子不总是整齐，人物会省字、改口、说半截话，老师做错决定时也更像现实中的惯性反应，而不像作者为了触发剧情强推角色。这正是本轮希望逼近的“未经加工、真假难辨”的一部分。

代价也很清楚：它的剧情忠实只有 16.50，空间与动作清晰度只有 7.75。两位裁判都判定它遗漏了电话中关于第二起异常的明确警告；高潮段落把多件事压在模糊的同时性里，后门、压制和老人重新站起的过程不如 Sol 清楚。它更像一名有现场口吻的快写作者，而不是可靠的设定执行者。

因此，Sonnet 最适合生成文风备选、改写对话和给成稿增加口语毛边，之后必须经过剧情节点与空间因果复核。

## 建议的生产分工

在更多场景样本出现前，建议采用分工而非选出唯一模型：

1. 常规章节初稿继续使用 `gpt-5.6-luna / max`。它在本轮仍排名第一，连载可读性、群像和恐怖节奏均衡。
2. 关键设定章、动作空间复杂章和最终剧情校验使用 `gpt-5.6-sol / xhigh`。它的标准差仅 1.92，剧情忠实 18.75、空间清晰 9.75，都是最稳的控制项。
3. 选定的重点章节可让 Claude Opus 做一次独立试写或深度文风修订，重点吸收生活动作、自然解释和非模板化观察，再由 Sol 或连续性审查收口。
4. 当初稿过于工整、对话像轮流发言时，可让 Claude Sonnet 只做“人物声音与网络毛边”版本；不得让它自行增删冻结剧情节点。

这一分工把 Claude 当作新的风格能力，而不是简单替换 Luna 或 Sol。单凭一个教室群像场景，还不足以把整部长篇切换到 Opus 或 Sonnet。

## 按量模型与评审模型

DeepSeek V4 Flash 和 MiMo V2.5 复用首轮原始输出，没有产生新的按量生成调用。加入 Claude 后，两者分别排第五和第八，均没有进入前二，也没有达到预先冻结的采用门槛，因此当前仍没有按量使用的理由。

Gemini 3.1 Pro 连续两次无法处理 111,501 字节的九候选统一评审提示，分别在 12.658 秒和 8.421 秒后返回空内容。本轮保留失败记录，并让 Claude Opus 使用完全相同、哈希一致的提示补位。Gemini Pro 不宜继续承担大面板裁判；若还要评估其判断力，应把候选拆成更小的固定批次，而不能把拆批成绩与本轮直接混算。

## 下一轮需要验证什么

本轮场景同时包含校园群像、封闭空间和异常动作，能检验对话、恐怖节奏与空间因果，却不能代表整部长篇。下一轮至少应再选两种非同质片段：一个低对白、重内心判断或独行探索的场景；一个跨场景、含信息伏笔和人物关系推进的场景。仍应冻结同一提示结构并盲评，重点观察：

- Sonnet 的“活”能否离开群像对白后继续成立；
- Opus 是否反复为了自然细节改动既定因果顺序；
- Luna 的高分是否跨场景稳定，还是受单个裁判离群值影响；
- Sol 的稳定是否会在情绪与人物关系场景中变成过度工整。

完成这组交叉场景验证后，再决定是否把 Claude 固化进章节流水线，会比依据单一样本切换主模型可靠。
