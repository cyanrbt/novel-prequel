# 全书剧情设定多维独立审查与修订记录（2026-08-22）

## 审查对象

- 初版剧情圣经：`novel/plots/full_series_plot_bible.md`
- 初版提交：`9f35cdc`（`design: establish full-series plot bible`）
- 审查范围：六卷主线、原著衔接、人物能力与代价、时间线、因果闭环、人皮纸起源、王家与鬼眼支线、读者爽感及连载节奏。
- 审查方式：三名 sub agent 在不互相改稿的前提下独立阅读同一版设定，分别从正典兼容、因果时间、读者体验三个维度提出问题；主代理逐项裁决并同步到总纲、事件卡、时间线、角色卡与注册表。

## 一、正典兼容审查（canon_audit）

### 主要结论

初版没有必须推翻的正典级冲突，张洞晚年得子、第二卷首次主动能力、罗文松早期能力边界、人皮纸的开放式起源、王家夫妇与鬼眼原主人等核心方案可以保留。

### 必须修订

1. 补入张洞临终前的红门会面：未来杨间打开红门，六名旧友同现；张洞由张伯华确认后来人已终结并全面封锁灵异，拒绝无意义比试，告别并向孟小董道歉。不能把结论弱化为“未来也许仍有人寻找办法”。
2. 删除“成熟能力压制尸体活性”的解释。活人阶段只排斥灵异青春和续命；活人寿命结束后进入原著所见的尸体复苏，尸体仍可使用成熟压制。
3. 保留鬼邮局601室名册悖论：罗文松、田晓月、张羡光的顺序与罗文松似乎很晚才死亡并存，不补成简单的死亡后线性继任，也不确认张羡光是坠楼凶手。
4. 301室保存的是张洞年轻画像，不是张洞保存孟小董画像。
5. 秦老终点顺序固定为长期驾驶灵异公交、晚年封存自身、最后一次苏醒后驾走幽灵船。

### 已确认安全的边界

- 王家一代固定为夫妇；成年王陆不进入1910—1920年代。
- 人皮纸1934年完成“身体、黑字、记忆、判断方式融合”，身份连续性不定案。
- 鬼眼原主人保持黑暗下身份未知，不归并为七老、王家或人皮纸来源。
- 秦不是第八老；张羡光固定为1942年出生、张洞与刘桂之子。
- 第二卷没有泛化失忆，也不连接报纸鬼。

## 二、因果与时间线审查（causality_audit）

### 必须修订

1. 第五卷原范围1945—1955与第六卷1954起点重叠。终版改为第五卷1945—1953，第六卷1954年至现代。
2. 张洞的能力形成缺少中间因果。终版补成：第一卷两种作用在右臂留下互扰残余；第二卷有意识复现“共同沉寂”，首次主动压制；第五卷 `M5-BALANCE-LOCK` 把两种残余锁成长期互相死机，解释百岁寿命、复苏稳定和无法灵异续命。
3. 第五卷长期封印缺少拓扑。终版为身份重演、棺下影、无主交接分别锁定长期节点、触发方式、切断动作、维护人、拒绝／转移条件与首个失效信号。
4. 第六卷不能只列人物退场。终版建立 `M6-SYSTEM-DECAY` 衰败账簿，让每名成员的状态变化具体造成一个判断或补位缺口。

### 重要桥接修订

- 第二卷增加何小满这条普通生活线，把1915、1919、1922—1924、1927四次跳年通过工作、文书与公共接收职责串起来。
- 第四卷锁定1937—1938、1939—1941、1941—1942、1945四段微时间线；返程线在本卷关闭，不进入第五卷成为第四条灾链。
- 人皮纸的受限弱鬼失踪只发生在1919年；1934年转化现场不重复第二次吞鬼疑点。
- 李庆之死亡早于白水镇异常映照的“三年前时间点”，肉身留酒店、坟另存且内容未知。
- 王陆在第四卷末至第五卷间是孩子，第六卷后段才以成年驭鬼者活动；不锁精确出生年。
- 人皮纸第五卷载体固定为第四卷已建立的贺永安，避免临时出现功能人物。
- 补足孟小董选择301室、张幼红五人沉睡协议、秦提出古宅地点、罗文松接受及离开管理者位置的中间动机。

## 三、读者体验与商业节奏审查（reader_audit）

### 初版风险

- 第三卷同时承担五老出场、人皮纸诞生、七人结成、鬼眼关押，缺乏一宗可复述的主事件，张洞容易沦为群像导游。
- 第五卷的“三条灾链”在实际叙述中变成四条，且缺少地点、倒计时、具名待救者和标志性画面。
- 第六卷虽然声称不写年表，结构仍接近人物退场清单。
- 人皮纸各卷欲望变化不够具体，容易只剩“给真信息但隐瞒代价”的重复技巧。

### 终版处理

1. 第三卷只保留“双桥旧木造成错门”这一宗主事件；每个章节群只前景化两至三名新人。张洞凭两种冷痛识别同一作用链，并掌握最后关门时机。
2. 弘法寺与鬼眼关押是错门终局误接既有空间后的后果，不是平行追加大事件，也不把鬼眼原主人反写成错门源头。
3. 第五卷固定主舞台“江岸接收总栈”，以天亮盖下产权印为倒计时；何小满、贺永安和第四卷迁徙家庭提供具名待救者。
4. 第五卷维持三条主作用：旧封存链、无主交接链、人皮纸第三方。王家支线在关系层并行，不与总栈封印抢同一高潮层。
5. 第六卷由“最后一个无人接班的位置”贯穿。只给孟小董、罗文松、张洞完整告别，其他人通过遗物、协议偏差和节点失效进入同一因果链。
6. 人皮纸建立逐卷目标阶梯：训练省略、保住叙述、控制撤离队、争取贺永安载体、依靠一次真实交易流入民间；每卷均有目标失败或被迫重写。
7. 增加普通生活回报与黑色幽默：识字学账、复工开课、药铺与饭桌、错票与无地址信件。惊悚后的收益先成立，后续失去才有重量。

## 四、争议项裁决

| 审查建议 | 裁决 | 原因 |
| --- | --- | --- |
| 将张洞第一次主动能力提前到第一卷 | 不采纳 | 用户已确认第二卷首次主动。改为第一卷获得稳定、可重复的被动差异并完成一次规则反杀，既给爽点又保留成长闸门。 |
| 将鬼眼原主人直接设为第三卷错门根源 | 不采纳 | 会把两条原著留白强行统一。终版只让错门意外接入既有空间，鬼眼关押成为共同限制的后果。 |
| 第三卷减少五老出场任务 | 采纳但不删角色 | 五老仍在同卷交叉出现；每个章节群只突出两至三人，其他人通过远端行动、物证和稍后接棒参与。 |
| 第五卷把返程线算入终局 | 不采纳 | 返程线在第四卷完成并提供李庆之守位结局；第五卷只处理旧封存、无主交接与人皮纸第三方。 |
| 解释鬼邮局三任管理者全部时间关系 | 不采纳 | 原著本身保留悖论，强行线性解释会制造更大正典风险。 |

## 五、终版仍主动保留的未知

- 罗文松坠楼凶手、田晓月状态、三任管理权是否重叠及鬼邮局创建者。
- 人皮纸转化后的意识归属、第一人称选择算法、真话限制与吞鬼来源。
- 王家夫妇生前能力分工、诅咒技术原理、全家福与摆钟的完整关系。
- 鬼眼原主人黑暗下本体、棺材钉制造者及现代脱困后的去向。
- 李庆之坟中之物、孟小董道歉全部原因、张幼红多世复活完整机制、秦老生母与制造者。

这些未知不是待补漏洞，而是为原著留白和恐怖感保留的边界。正文可以给出相互竞争的证据，不能用全知旁白一次定案。
