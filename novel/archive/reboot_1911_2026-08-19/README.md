# 2026-08-19 新版连续性重启归档

本目录保存从正式连续性撤下的1908年开篇。撤稿不是删除：正文、元数据、合订本、长期记忆索引以及第2章结束后的完整状态都原样保留，可用于审计、素材回收和质量回归。

## 为什么再次重启

- 用户确认前传应从1911年前后、约十七岁的张洞起步，并完整覆盖1942年晚年得子、1950年代后长期守望以及杨间时代的古宅死亡；1908年、十八岁的运行状态已不再匹配新版时间线。
- 现有两章虽然经过多轮质量审核，仍承载上一版“死者重走还账路线”的连续性。新版第一卷需要重新围绕“家族守位制度、门外身份重演与棺下影是两类作用、张洞主动寻找非守位方案”建立因果，不能把旧章局部修补后冒充新起点。
- 旧状态、记忆索引与正文存在严格哈希绑定。直接修改年份会制造一套正文没有发生过的伪连续性，因此必须整体撤下、把正式状态原子重置为第0章。
