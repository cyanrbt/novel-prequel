# 第一卷素材取舍账本

| 材料 | 保留方式 | 删除或降级 |
|---|---|---|
| 母子离镇 | 作为全书“保护与决定权”原点；张洞为了带母亲逃走，将木样、行囊与船钱留在被占据的张家正屋 | 不再重复丢船、丢车、丢第二份工作 |
| 孙家案例 | 前两章已完成死者路线重演、一次成功阻止放行和一次放行后的直接求救；第3章必须处理孙有田在堂屋的结果 | 不再扩成完整证词调查和第二轮同构放行 |
| 门外客 | 利用被边界内之人承认为可以进入的身份；当前通过周秀兰的外观、声音和死前路线显现 | 不按门栓、暗号、称呼和口令逐条试验 |
| 棺下影 | 与门外客分属两层作用，祠堂段以旧物冷意、地下作用和实际伤害进入，后段互扰并把路径引向张洞 | 不用纸灰或替代性静态痕迹承担开篇恐怖 |
| 张大成旧死 | 推动父亲与叔公争夺守位解释权 | 不靠恰好掉出的残页一次揭底 |
| 守位名单 | 揭示家族把泄漏优先导向指定活人的制度 | 不把所有名单、钉位和修补数字都扩成独立谜题 |
| 叔公与父亲 | 两人都拥有有效而有害的方案；至少一人活着承担后果 | 取消“叔公死后父亲再死”的固定悲剧队列 |
| 母亲 | 保留谋生、自主和卷末不同选择；后续有实质回响 | 不长期作为每章被威胁、撤单和等待营救的人 |
| 李二 | 有自家生计与拒绝权，可形成一次互惠后分开 | 不作为固定调查跟班和证词运送员 |
| 大汉市与水路 | 连接清末工商业、人口流动和第二次异常接触 | 不重复旧货舱、失去交通和水鬼规则实验 |
| 七棺与十一钉 | 只保留“可见结构外还有更深缺口” | 不在第一卷解释后世棺材钉完整起源 |

## 使用原则

- 新章节优先消费正式人物伤口和当前选择，不为复用旧素材创造机会。
- 同一材料只承担一次主要不可逆损失；后续出现必须改变含义或人物关系。
- 材料不足以形成新场面动作时，可一句带过，不强制扩成章节。
