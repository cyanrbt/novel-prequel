# event_9：第六卷·守到后来

## 卷级定位

- 年代：1954年至杨间时代，只选择会改变家庭、成员状态或同一维护缺口的年份落笔。
- 起点：七人已完成需要活人长期维护的有限布局，人皮纸失去当时载体却保住本体，张羡光已经出生。
- 表层目标：处理“最后一个无人接班的位置”。1954年，一份从鬼邮局寄出的半块断木筹与维护记录抵达古宅，显示江岸总栈的备用接收处已在现实改名消失；此后每名成员退出都会让这一个空位接到更多风险。
- 核心问题：守住几十年是否已经算成功；后来者拒绝旧方案时，前代有没有资格强迫他们继续承担。
- 卷末出口：依次完成 `M6-SYSTEM-DECAY` 与 `M6-CANON-HANDOFF`。张洞在杨间时代的古宅葬礼中死亡、下葬，尸体复苏后继续管理老林；前传不改写原著事件结果。

## 时间跳跃纪律

1. 每次跨一年以上，跳跃前必须有一个尚未结束的关系或节点问题；跳跃后第一场用人物年龄、生活习惯、设施磨损或责任转手兑现变化。
2. 不逐年报告七人近况。只有具名成员退出、张羡光成长、刘桂家庭边界改变、王家一代完成亡魂转化或具体节点失效，才值得落笔。
3. 不给所有成员安排同年告别。原著只支持老一代与设施陆续失管，现代复苏来自累计失效，不是一场整齐的集体殉葬。
4. 历史年份只在改变人物生活时出现。1954年长江洪水可作为一次后世检验：现实社会负责公开抗洪，张洞等只防止地下旧节点制造额外伤亡。
5. 全卷只有孟小董、罗文松、张洞得到完整的正面告别场景；李庆之、张幼红、罗千、张伯华和秦的状态通过遗物、协议偏差或远端节点失效呈现，避免墓志铭合集。

## 第一阶段：和平第一次需要解释

- 张洞终于拥有一段不必每夜出门的家庭生活；刘桂继续拥有自己的工作、学生和离开危险地点的决定权，不成为守望者的照料员。
- 年幼的张羡光先真实享受父辈争取的安全：能上学、能与同龄人来往、能把父亲的古宅当作麻烦而非英雄圣地。
- 江岸总栈备用接收处在现实改名消失，半块断木筹和维护记录却被鬼邮局送到古宅，仿佛要求古宅签收“最后一个维护人”。木筹只证明旧交接，不强迫张洞服从；他可以拒绝，未结风险却会继续寻找现实接收处。
- 这个缺口迫使张洞在陪伴家人与继续守位之间作选择。不得用“天下苍生”一句话替代具体爽约、误解和补偿。
- 1954年洪水或同级现实压力冲刷地下边界。张洞可以守住一处额外灵异缺口，不能成为防洪功臣或解释真实胜利。
- 阶段出口：张羡光第一次看见所谓和平依赖父亲持续隐瞒与缺席，却也必须承认这套办法确实救过自己和身边人。

## 第二阶段：每少一个人，空位就多接一份风险

- 李庆之在白水镇异常映照的“三年前时间点”以前已经死亡，高大男尸仍留凯撒大酒店，坟已另存且内容未知。活人判断消失后，酒店第一次多出一条无人知道应否开启的走廊；不把男尸、鬼影和柴刀简化成一次主动分身仪式。
- 孟小董得到一场直接告别：过去反向占据现在使她选择死于301室，无法自由离开；她预留另一个自己参加张洞葬礼。301室保存的是张洞年轻画像，张洞的歉意在关系层闭合一半，不写成原著已确认婚约。
- 罗文松得到一场直接告别：管理者身份压住复苏，却使他无法同时照料家族、寻找邮局外特殊门和维护现实节点。他为补空位尝试离开，最终仍死在邮局外并从五层坠落；凶手、田晓月状态与张羡光责任均不定案。601室名册保留罗文松、田晓月、张羡光顺序及其时间悖论。
- 张幼红、罗千、张伯华和秦不各开退场副本：五名沉睡者协议出现一次身份偏差，坟场失去外出应急者，药箱最终停产或药铺关门，本应抵达的公交没有到站。每一项物证都把压力送回“最后维护人”空位。

### `M6-SYSTEM-DECAY` 衰败账簿

| 状态改变 | 原来提供的判断／补位 | 首个可见缺口 |
| --- | --- | --- |
| 李庆之死亡、肉身留守 | 判断酒店哪一道危险可放行 | 男尸继续封锁，新增岔路却无人判断 |
| 孟小董死于301室 | 主动选择何时让过去介入 | 多名过去自我复苏，只有预留的一次仍服从旧约 |
| 张幼红第一世结束 | 以本人意志校正复制和沉睡协议 | 后世人格混入新记忆，保存成功却偏离原约 |
| 罗千被坟场彻底绑定 | 临时离场为其他节点埋葬当下 | 坟场外泄漏失去应急埋葬者 |
| 罗文松坠楼死亡 | 以活人判断处理无主交接 | 管理空缺与敲门拼图同时外泄 |
| 秦晚年封存自身 | 公交跨节点补送人鬼 | 远端节点失去最后机动补位 |
| 张伯华最终凋零 | 灵异药让维护者争取下一次行动 | 各节点只能自行承受侵蚀 |
| 张洞活人寿命终止 | 古宅仍有活人协调与否决 | 尸体能压制老林，不能替活人维护全网 |

- 表格锁定因果而非未经正典确认的精确死亡先后。现代复苏来自缺口累计，不由张洞或任何一人死亡单独触发。

## 第三阶段：后来者拒绝继承

- 张羡光从“父亲为什么总不在”成长到“为什么所有安全都要有人永远留在里面”。他的鬼画桃花源路线必须从长期生活经验推出，不靠某一夜突然黑化。
- 张洞必须正面承认：自己虽反对叔公指定守位，却同样把古宅、邮局、坟场和儿子的人生当作可安排的后续位置。
- 父子在最后接收处再次失控时真正合作：张羡光借鬼画方向临时迁走一批活人，张洞压住追入的作用。两种方案缺一不可，分歧建立在双方都能救人之上。
- 秦作为后继协作者逐渐承担跨节点运输：先长期驾驶灵异公交，晚年因寿命与身体状态主动封存自身，最后一次苏醒后驾走幽灵船。顺序服从正典；精确出生、生母与制造者仍不终解。
- 王家夫妇在少量时间锚中死亡并化作保护王陆的黑白亡魂。王陆只在本卷后段以成年驭鬼者活动，真心接受安全与遗产；不复写王察灵现代主线，也不提供解除按钮。
- 阶段出口：张羡光选择自己的路线，张洞不再把拒绝视为背叛，却仍决定由自己守到身体死亡。

## 第四阶段：红门、告别与古宅葬礼

- 张洞越来越少主动出手，不是因为失去判断，而是每次离开古宅都会让老林和节点出现更大缺口。
- 旧队友的死亡与设施失管在远处形成压力，但最后一段仍以张洞能够感知的家庭、古宅和葬礼准备为中心，不用全知地图播报全球复苏。
- 葬礼以前，未来杨间打开红门，连接到临终前的张洞一侧，六名旧友也因这扇门同时出现。张洞本能起身准备援助，随后由张伯华明确告知：后来人已经真正终结并全面封锁灵异，前代等待的最好结果已经发生。
- 张洞因活人寿命将尽而拒绝无意义的称量或比试，向旧友告别，并向孟小董道歉。正文只写张洞一侧的确认与放下，不复写杨间现代主线，不把结果降格成“未来也许还有人寻找办法”。
- 葬礼、入殓、出殡与下葬必须停在原著允许的结果，不改变杨间等现代人物的选择，不夺走他们完成古宅事件的功劳。
- 张洞死后复苏的尸体继续管理老林是正典结果。若正文保持张洞单一限知，意识终止后只用极短的物证式尾声确认林中秩序重新闭合，不进入尸体内心，也不替它声明仍是张洞。
- 完成 `M6-CANON-HANDOFF`：前传回答旧一代如何走到这里；红门确认、葬礼与尸体复苏均停在正典边界，不重写原著从这里以后怎样发生。

## 人皮纸的最后边界

- 只完整写一次普通人的交易：人皮纸给出一条有真实眼前收益的信息，对方据此主动把它从未登记遗物带入旧书或私人收藏链；纸上的“我”不机械改成持有者。
- 其余几十年转手全部留白，不用数个同构案例把尾声写成追踪年表。
- 不写它自行跨城，不点名方镜一家，不提前出现杨间姓名，也不复刻原著固定开场句。
- 它是旧时代另一种“守到后来”的方式：七人用身体和地点维持，人皮纸用信息依赖让别人继续携带。前传只完成对照，不安排现代相遇。

## 两层回看兑现

1. **时代层**：读者看到真正推动历史的是工人、教师、司机、医者、抗洪者与普通家庭；民国驭鬼者做的是阻止灵异暗面把这些努力吞掉。
2. **原著层**：古宅、老林、邮局、坟场、301室、药铺、酒店、公交、王家亡魂和人皮纸不再是同时出现的设定名词，而是一群人几十年选择彼此冲突后留下的不同答案。

## 禁止项

- 不把第六卷写成连续年表、人物墓志铭合集或现代原著剧情摘要。
- 不让七人在同一天集体死亡，不让张洞一死便单独触发全球全面复苏。
- 不给每项著名灵异物品补制造者，不让张洞成为所有现代事件的共同幕后安排者。
- 不确定罗文松坠楼凶手、李庆之坟中物、秦老生母、孟小董道歉全貌、张幼红复活原理和人皮纸现代流转终点。
- 不把刘桂写成奖励英雄的妻子，不把张羡光写成单纯逆子，也不把孟小董拉入三角恋。
- 不让张洞永久杀死真鬼、获得全知预言或把杨间当作自己精准等待的指定救世主。
